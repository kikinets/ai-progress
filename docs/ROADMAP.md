# Roadmap AI Engineering

Objetivo: llegar al bootcamp de AI Engineering de Ironhack con una base sólida.

Los datos que usa la app están en `data/roadmap.json`; este archivo es la versión legible. Si cambias uno, cambia el otro.

## Fase: preparación pre-bootcamp (2 al 29 de noviembre de 2026)

### Semana 1 (2 al 8 nov): Python de verdad y entorno de trabajo
Instalación de herramientas, entornos virtuales, Python básico y POO, type hints, Jupyter y prework de Ironhack.
**Entregable:** herramienta CLI (gestor de gastos con CSV) en un repo con README.

### Semana 2 (9 al 15 nov): datos y las matemáticas justas
NumPy, Pandas, visualización, SQL básico, álgebra lineal, gradiente y probabilidad.
**Entregable:** EDA de un dataset de Kaggle con 3 a 5 conclusiones.

### Semana 3 (16 al 22 nov): machine learning clásico
Supervisado y no supervisado, validación, modelos clásicos, métricas, scikit-learn e intuición de redes neuronales.
**Entregable:** clasificador con scikit-learn explicado con SHAP.

### Semana 4 (23 al 29 nov): LLMs y tu primera app con IA
Tokens, embeddings y transformers, prompt engineering, API de un LLM, RAG, agentes y fin del prework.
**Entregable:** mini app en Python que use la API de un LLM.

## Fase: bootcamp Ironhack
Fechas y semanas pendientes hasta que Ironhack pase el temario.
