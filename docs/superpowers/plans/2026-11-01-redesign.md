# AI Progress v2 Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild AI Progress as a polished dark desktop app with a Today dashboard, study timer, task drawer with notes, XP/levels/badges and a day-by-day study plan, without losing v1 progress.

**Architecture:** Rust owns all data and domain logic (roadmap v2 types and validation, progress v2 store with migration, streak, stats, sessions, XP, badges) and exposes Tauri commands returning a `ProgressView`/`ProgressUpdate`. The React UI is a sidebar shell with five screens built from a small in-house component kit; a dev-only `mockIPC` backend lets every screen run in a plain browser for visual checks.

**Tech Stack:** Tauri 2, Rust (serde, chrono, keyring, reqwest), React 19, TypeScript, Vite, Tailwind CSS v4, Motion, React Flow, Radix Dialog/Tooltip, cmdk, lucide-react, canvas-confetti, react-markdown, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-01-redesign-design.md`

## Global Constraints

- UI only renders and animates; file, network, clipboard, notification access and all domain logic (streak, XP, levels, badges, stats, sessions) live in Rust and are covered by `cargo test`.
- `roadmap.json` is read-only and embedded; `progress.json` lives in the app data dir; progress references tasks by `id`.
- No API keys in code or git.
- Animations 150-300 ms; progress uses springs (`visualDuration: 0.4, bounce: 0.15`); respect `prefers-reduced-motion` (only fades remain).
- Dark theme default, light equivalent; single progress accent: gradient `#8B5CF6` → `#22D3EE`.
- Fonts Geist / Geist Mono, local via `@fontsource-variable/*`.
- Window 1280×820, min 1024×700.
- Code, names and commits in English; UI copy in Spanish.
- All Rust time logic is generic over `Tz: chrono::TimeZone` and takes `now` as a parameter; commands pass `Local` and `Local::now()`.
- Every commit leaves the app building (`npm run build`, `cargo test`, `npm test` pass).

## Review Focus

1. **Real v1 `progress.json`** (e.g. `{"version":1,"completed":{"w1-setup":"…"}}`) must load as v2 with the same tasks completed and a `progress.v1.backup.json` beside it → test in Task 2.
2. **App closed with the timer running and reopened hours later** must not log a 10-hour session: stale sessions close at a 4 h cap → test in Task 6.
3. **Double-clicking "Estudiar"** must not create two active sessions: `start` errors when one is active → test in Task 6.
4. **A session that crosses midnight** counts toward the day it started; a task completed at 00:30 local counts for that local day, not the UTC day → tests in Task 5 with a `+01:00` offset.
5. **Unchecking a task after earning a badge** keeps the badge but removes the task's XP → test in Task 10.
